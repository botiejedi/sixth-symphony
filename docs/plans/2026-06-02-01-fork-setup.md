## Task 9: Add a smoke test that runs in CI-able fashion

**Files:**
- Create: `tests/smoke/extension-build.test.mjs`
- Modify: root `package.json` — add `test:smoke` script

We add one repo-level smoke test that proves the extension build artifact exists and contains a manifest. It uses Node's built-in test runner (no extra deps).

**Step 1: Write the failing test**

`tests/smoke/extension-build.test.mjs`:

```javascript
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync, existsSync } from 'node:fs';
import { resolve } from 'node:path';

const distDir = resolve(process.cwd(), 'extension/dist');

test('extension build output exists', () => {
  assert.ok(existsSync(distDir), 'extension/dist/ should exist (run `npm run build:extension` first)');
});

test('extension build contains a valid manifest', () => {
  const manifestPath = resolve(distDir, 'manifest.json');
  assert.ok(existsSync(manifestPath), 'extension/dist/manifest.json should exist');
  const manifest = JSON.parse(readFileSync(manifestPath, 'utf8'));
  assert.equal(manifest.manifest_version, 3, 'should be a Manifest V3 extension');
  assert.ok(manifest.name, 'manifest should have a name');
});
```

**Step 2: Add the script to root `package.json`**

Edit `package.json` — append to the `scripts` block:

```json
    "test:smoke": "node --test tests/smoke/"
```

(Mind the trailing comma on the preceding line.)

**Step 3: Run the smoke test against a stale build (expect pass)**

Run: `npm run build:extension && npm run test:smoke`
Expected: both tests pass.

**Step 4: Run the smoke test against a missing build (expect fail)**

```powershell
Remove-Item -Recurse -Force extension/dist
npm run test:smoke
```

Expected: first assertion fails with "extension/dist/ should exist". This confirms the test actually checks what we think.

**Step 5: Restore the build before committing**

Run: `npm run build:extension`
Expected: dist re-created, smoke test passes again.

Run: `npm run test:smoke`
Expected: pass.

**Step 6: Commit**

```powershell
git add tests/smoke/extension-build.test.mjs package.json
git commit -m "test: add repo-level smoke test for extension build"
```
